# 检索置信度阈值校准

> 目的:整合到 xzy 后端时,他的置信门控(§0.2)靠检索 `score` 判断「转人工 / 追问 / 可答」。
> 但那套阈值(0.60/0.72/0.80)是按他原来的 **BM25** 校准的;换成我们的**四层检索(向量+BM25+RRF+Cohere rerank)**后,`score` 的语义和尺度都变了,**必须重新校准**。
> 本文档给出校准结论 + 与 xzy 门控的换算,供整合对接。
> 复现:`python scripts/calibrate_threshold.py`(分数存 `data/calibration_scores.json`,`--analyze` 只分析不重跑)。

---

## 1. 方法

跑评估集 `eval_set.jsonl` 全部 65 题(60 有答案 + 5 无答案),记录每题 top1 的 rerank score。
- **有答案题**:score 应偏高(该判「可答」)
- **无答案题**:score 应偏低(该判「没有 / 转人工」)
- 两组能否用一条线分开,就是能否校准阈值。

---

## 2. 结果:分数分布

| 组 | 题数 | 最低 | 中位 | 最高 |
|----|------|------|------|------|
| 有答案 | 60 | 0.097 | **0.991** | 1.000 |
| 无答案 | 5 | 0.002 | 0.009 | **0.460** |

**主体分得很开**:有答案题多数 ≥ 0.9(中位 0.991),无答案题 4/5 ≤ 0.024。但存在一个重叠区(见 §4)。

无答案题逐条:

| 题 | score | 问题 |
|----|-------|------|
| n03 | 0.0020 | 毕业生平均起薪 |
| n02 | 0.0057 | 项目 QS 排名 |
| n05 | 0.0085 | 能否延期入学 |
| n04 | 0.0236 | 能否申请 TA 职位 |
| n01 | **0.4602** | 是否提供住宿 ← 唯一的高分无答案题 |

---

## 3. 推荐阈值 + 与 xzy 门控的换算 ⭐

**核心:我们检索的 0.05 ≈ 他 BM25 的 0.60。** 不能直接套他的数,要按下表换算:

| xzy 门控档位 | 他原来的线(BM25) | 换成我们的检索 | 效果 |
|-------------|------------------|---------------|------|
| **可答** | ≥ 0.72 | **≥ 0.15** | 55/60 有答案题直接答 |
| **追问澄清** | 0.60 – 0.72 | 0.05 – 0.15 | 低分有答案题走澄清 |
| **转人工 / 没有** | < 0.60 | **< 0.05** | 挡住 4/5 无答案题 |

**为什么"没有"线定 0.05**:
- 挡住 n02/n03/n04/n05(0.002~0.024)✅
- 不误杀任何有答案题(最低的 q44=0.097 > 0.05)✅ —— 漏答 0/60
- 唯一漏网:n01 住宿题(0.46),靠回答 prompt「资料不足就说不知道」兜底

---

## 4. 已知问题:重叠区(待优化,非阻塞)

无答案题最高分 **0.46**(n01 住宿)> 有答案题最低分 **0.097**,存在重叠——**单靠 rerank 分数无法完全干净地区分有/无答案。**

根因是 **5 道「有答案但低分」的题**,说明检索对它们捞得不够好:

| 题 | score | 问题 | 疑点 |
|----|-------|------|------|
| q44 | 0.097 | offer 后该做什么 | |
| q34 | 0.108 | 一年几次 intake | |
| q01 | 0.143 | 学费多少(中文) | ⚠️ 英文同题 q02 = **1.000**,中英文严重不平衡 |
| q03 | 0.229 | 录取后的接受费 | |
| q38 | 0.380 | 申请结果何时公布 | |

> **q01 vs q02** 是最值得查的信号:同样问学费,中文 0.143 / 英文 1.000。可能是中文检索的系统性缺陷,修好或能一次改善一批中文题。

**影响**:重叠区里,阈值取任何值都会有取舍(放行 n01 或误杀 q38/q26)。当前选择:阈值取低(0.05)保证不误杀有答案题,n01 交给 prompt 兜底。

---

## 5. 结论

1. **可以校准**:两组主体分得开,给出可用阈值。
2. **对接 xzy**:门控三档换算见 §3(可答 ≥0.15 / 追问 0.05–0.15 / 转人工 <0.05)。
3. **待优化(会上讨论)**:5 道低分有答案题,尤其 q01/q02 中英文不平衡 —— 修检索比调阈值更治本。
4. **待重跑**:检索或数据变动后,重跑 `calibrate_threshold.py` 更新本表。
